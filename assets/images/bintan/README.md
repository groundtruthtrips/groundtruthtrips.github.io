Drop images for this edition here, then reference them from
`_editions/bintan-2026.md` front matter.

Suggested files (none are required — the layout falls back to a
gradient placeholder when a path is missing or empty):

- `hero.jpg` — wide banner image, referenced via `hero_image`
- `pengudang.jpg`, `bees.jpg`, `langur.jpg`, ... — one per activity,
  referenced via the `image:` key on each entry in `activities:`

Recommended: landscape photos, at least 1600px wide, optimized/compressed
before committing.
